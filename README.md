# Aegis

**Version:** 0.5 Beta (v0.5.0-beta)

A Minecraft Fabric 1.21.4 cheat client.

## Features

- Combat modules (Aura, AutoCrystal, Velocity, and more)
- Movement enhancements (Fly, Speed, Jesus, Phase, etc.)
- Render options (ESP, HUD, Custom models, Visual effects)
- Utility modules (AutoTool, Nuker, FreeCam, etc.)
- Built-in command system
- ClickGUI with customizable themes
- Discord RPC integration
- Account manager with Microsoft authentication

## Installation

1. Install Fabric Loader for Minecraft 1.21.4
2. Download the latest Aegis build
3. Place the jar file into your `mods` folder
4. Launch Minecraft with Fabric profile

## Building from Source

```bash
./gradlew build
```

The compiled jar will be in `build/libs/`
